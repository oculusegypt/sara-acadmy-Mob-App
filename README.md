# 🪐 منصة سارة العربي للتعليم الإلكتروني — Sara Al-Araby Academy (React & Vite)

> **منصة تعليمية إلكترونية عربية متكاملة أُعيدت كتابتها من تطبيق Android إلى تطبيق React عصري فائق السرعة** — فصول تفاعلية حية، مرشد سقراطي ذكي مدعوم بنماذج Gemini، لوحات متكيفة لجميع الفئات العمرية (براعم، أبطال، عباقرة)، مكتبة رقمية وكتب مصورة، نظام تحقق من الشهادات الرقمية، ولوحات متخصصة لأولياء الأمور والمعلمة والإدارة.

---

## ✨ أبرز الميزات والخدمات المنقولة

| | الميزة | التفاصيل وكيف تعمل في التطبيق |
|---|---|---|
| 🤖 | **مرشد سارة السقراطي** | استدعاءات حقيقية لخوادم Gemini مع تلقين سقراطي يوجه الطفل للتفكير واستنتاج الحل بدلاً من إعطائه الإجابة الجاهزة. |
| 🧮 | **تحدي الحساب الذهني والسوروبان** | ألعاب ذهنية تفاعلية متدرجة المستويات (عصافير، أبطال، عباقرة) مع نقاط خبرة XP، سلاسل أيام متتالية، وحسابات فورية. |
| 🧒 | **لوحة الطالب المتكيفة** | واجهات مخصصة حسب الفئة العمرية (براعم سارة حتى 6 سنوات، أبطال سارة 7-8 سنوات، عباقرة سارة 9-14 سنة). |
| 🎥 | **الفصل الافتراضي الحي (Studio)** | غرفة بث ومحاكاة مباشرة مع مشاركة شاشة، مزامنة صفحات المذكرات والكتب (PDF Book Sync)، ودردشة تفاعلية. |
| 📚 | **المكتبة الرقمية والملازم** | استعراض وتحميل ملازم نور البيان، كراسات تمارين السوروبان، والرياضيات الذكية مع فهرس الفصول. |
| 🎓 | **نظام الشهادات والتحقق** | إصدار تلقائي لشهادات التخرج الرقمية مع كود تحقق مشفر وفاحص باركود للتحقق من مصداقية الشهادة. |
| 👨‍👩‍👧 | **بوابة أولياء الأمور** | متابعة حضور الأبناء، تقديم اعتذارات الغياب، واختيار مواعيد التعويض بدون تعارض في الجداول. |
| 👩‍🏫 | **لوحة المعلمة سارة العربي** | إدارة المجموعات، تصحيح الواجبات وإسناد الدرجات والملاحظات، واعتماد طلبات الانضمام. |
| 🛡️ | **لوحة الإدارة والعمليات** | سجل التدقيق الزمني للحركات (Audit Logs)، إدارة المسجلين، وتتبع الحجوزات والمدفوعات. |
| 💳 | **حجز الاستشارات وبوابة الدفع** | استمارة حجز مقاعد واستشارات، محرك كوبونات الخصم، وإيصالات دفع مفصلة. |

## 🚀 التشغيل والتطوير

```bash
# تثبيت الاعتماديات
npm install

# تشغيل بيئة التطوير (على المنفذ 3000)
npm run dev

# بناء النسخة الإنتاجية
npm run build

# فحص الأنواع الصارم
npm run lint
```

## 🏛️ الهيكل البرمجي (Architecture)

- `src/components/` — مكونات الواجهة (الرئيسية، الحساب الذهني، الكتالوج، المشغل، الاختبارات، الشهادات، الحجز)
- `src/portals/` — بوابات النظام المستقلة (الطالب، ولي الأمر، المعلمة، الفصل الحي، الإدارة)
- `src/services/` — خدمات الربط مع الخادم (API)، مرشد Gemini، الوسائط، والـ Realtime WebSocket
- `server/` — خادم Express متكامل يقدم مسارات REST والذكاء الاصطناعي وWebRTC Signaling ويوفر وسيط Vite في وضع التطوير
